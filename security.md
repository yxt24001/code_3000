Intended Users of Code and Repo:
The code and data for this repo is strictly for academic use for CSE 3000: Contemporary Issues in Computer Science and Engineering.
The code and data for assignments are on this repo, and will be used for submitting homework and as examples for working with Jupyter notebooks.

Security Threats
1. Code can be exploited and sensitive data can get leaked. It is important that files committed to the repo do not contain any sort of personal data.
2. Malware attacks where repositories are cloned with malicious code to steal data.

Steps Taken To Secure Repo
1. Addition of a pull request ruleset file based on the example provided in class.
2. Enabled 2FA for logging into GitHub.
3. A CODEOWNERS file exists from the original forked repo.

Since this repo is only being used for this class, I don't feel the need to take more steps to secure the repo past what I have already.
